##### `// 01 · overview`

I build and ship small SaaS products end-to-end — backend, auth, data model, and the interface on top. Studying Big Data Analytics, but the working half of my week is spent in operations logic and shipped code: Cloudflare Workers on the backend, typed Firestore schemas underneath, and interfaces that don't need a manual on top.

I care more about *why* a system is correct than whether it merely works — atomic transactions over optimistic patches, gating logic that fails safe, not silent.
